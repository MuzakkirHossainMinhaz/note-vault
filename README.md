# NoteVault

NoteVault is a notes and posts application with a REST API and a React frontend.

- [Backend](./note-vault-backend/): Express, TypeScript, MongoDB API. See the [backend README](./note-vault-backend/README.md).
- [Frontend](./note-vault-frontend/): React and Vite web application. See the [frontend README](./note-vault-frontend/README.md).

## Live deployments

- Frontend: <https://note-vault-web.vercel.app>
- Backend: <https://note-vault-server.vercel.app>
